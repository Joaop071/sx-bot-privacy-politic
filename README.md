Política de Privacidade

Última atualização: 24 de setembro de 2026

Esta Política de Privacidade explica como o bot de Discord sx bot ("Bot", "nós" ou "nosso") coleta, utiliza e protege informações quando é utilizado em servidores do Discord.

1. Informações coletadas

O Bot pode processar as seguintes informações necessárias para executar suas funções:

- ID do usuário do Discord;
- Nome de usuário e informações básicas disponibilizadas pelo Discord;
- ID do servidor;
- ID de canais;
- ID de cargos;
- Informações relacionadas a ações de moderação, como mute, kick e ban;
- Mensagens ou eventos necessários para identificar e executar comandos de moderação.

O Bot não solicita senhas, tokens de usuário ou informações financeiras.

2. Como utilizamos as informações

As informações processadas pelo Bot são utilizadas exclusivamente para:

- Executar comandos solicitados pelos usuários autorizados;
- Aplicar ações de moderação, como mute, kick e ban;
- Adicionar ou remover o cargo de usuário silenciado;
- Identificar usuários e servidores durante a execução dos comandos;
- Manter o funcionamento e a segurança do Bot;
- Registrar informações técnicas de moderação, quando necessário para o funcionamento do Bot.

3. Armazenamento de dados

O Bot pode armazenar determinados identificadores técnicos, como IDs de usuários, servidores, canais e cargos, quando necessário para seu funcionamento.

Não vendemos, alugamos ou comercializamos informações pessoais dos usuários.

4. Compartilhamento de informações

Não compartilhamos informações pessoais dos usuários com terceiros para fins comerciais.

As informações podem ser processadas pelos serviços necessários para hospedar e executar o Bot, sempre que isso for necessário para seu funcionamento.

5. Exclusão de dados

Caso você queira solicitar a exclusão de dados relacionados ao Bot, entre em contato com o responsável pelo Bot através do servidor de suporte ou pelo meio de contato disponibilizado pelo desenvolvedor.

Quando a exclusão for tecnicamente possível e não houver necessidade legítima de manter determinado registro, os dados serão removidos.

6. Segurança

Adotamos medidas razoáveis para proteger as informações processadas pelo Bot contra acesso, alteração ou divulgação não autorizada.

Entretanto, nenhum sistema conectado à internet pode garantir segurança absoluta.

7. Discord

O Bot funciona através da plataforma Discord. A utilização do Discord também está sujeita às políticas e aos termos do próprio Discord.

Para consultar a Política de Privacidade do Discord, acesse:

https://discord.com/privacy

8. Alterações nesta Política

Esta Política de Privacidade poderá ser atualizada periodicamente para refletir alterações no funcionamento do Bot ou nas práticas de tratamento de dados.

Quando houver alterações relevantes, a data de atualização no início desta página será modificada.

9. Contato

Para dúvidas, solicitações ou questões relacionadas à privacidade, entre em contato com o responsável pelo Bot através do canal de suporte disponibilizado no servidor oficial.
